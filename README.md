# The Tapestry of Aethra

A reference codex for *Aethra* — an original high-fantasy world spanning four cosmological realms, eight continents, twenty-five schools of magic, one hundred sentient races, and centuries of history.

**🔗 Live site:** https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/

## What's in here

- `index.html` — the full interactive codex (single self-contained file: HTML, CSS, and JS all in one, no build step needed)
- `LICENSE.txt` — copyright and usage terms

## About the codex

The site is organized into fourteen Parts covering:

- Cosmological structure (the Four Realms)
- The eight continents and their nations
- The Grand System of Arcadia (magic)
- Peoples of Aethra (100 races) and their languages
- The Magical Beasts Directory
- Legendary heroes, villains, wars, and catastrophes
- Regional flora, fauna, and monsters
- Culture: law, holidays, cuisine, fashion, architecture
- Religion, noble houses, trade, and guilds

Use the sidebar to browse by Part, or press **⌘K / Ctrl+K** to search the entire codex.

## Running it locally

No dependencies, no build step — just open `index.html` in any browser.
